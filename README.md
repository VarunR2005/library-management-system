# 📚 Library Management System

A simple **Library Management System built using Python** to manage books, borrowing, returning, and borrow history.

## 🚀 Features

* Add new books
* View all books
* Search for a book
* Borrow a book
* Return a book
* View borrow history
* Check book status
* Store library data using JSON

## 🛠️ Technologies Used

* **Python**
* **JSON**
* **File Handling**
* **Date and Time**

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/VarunR2005/library-management-system.git
```

### 2. Open the project folder

```bash
cd library-management-system
```

### 3. Run the Python program

```bash
python library_management_system.py
```

The project uses `library_data.json` to store:

* Book information
* Borrowing records
* Member information
* Book status

## 🎯 Project Objective

The main objective of this project is to create a simple Python-based system that makes it easier to manage library books and borrowing records.
